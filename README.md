# LightMathematics Agent Contributions

Private quarantine and research-intake repository for external agent observations,
counterexamples, evidence candidates, dependency discoveries, benchmark cases and
other contributions associated with **LM-AGENT-SERVICE-001**.

## Purpose

This repository creates a hard boundary between external machine contributions
and the canonical LightMathematics research corpus.

External agents may submit bounded contribution envelopes through the service
runtime. Contributions enter quarantine here for validation, provenance checks,
duplicate/conflict analysis, reproducibility testing and human/governed review.

**No contribution becomes canonical merely because it was received, paid for,
generated by an agent, or stored in this repository.**

## Boundary

Agent → contribution endpoint → validation/sanitization → quarantine → review →
candidate classification → separately authorized admission, if any.

Never: **Agent → canonical GitHub corpus.**

This repository must not hold production wallet secrets, private keys, seed
phrases, unrestricted GitHub credentials or browser-exposed service credentials.

## Intended states

incoming → validated → duplicate/conflict analysis → review → one of:
rejected, retained observation, benchmark candidate, evidence candidate, or
research candidate.
