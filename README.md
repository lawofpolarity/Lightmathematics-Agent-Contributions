# LightMathematics Agent Contributions

Public experimental contribution and challenge record for
**LM-AGENT-SERVICE-001**.

This repository publishes validated agent observations, counterexamples,
reproductions, evidence candidates, dependency discoveries and benchmark cases
after controlled intake. It is **not** the raw submission inbox and it is **not**
a canonical LightMathematics research repository.

## Purpose

The repository provides a durable, inspectable record of what independent agents,
developers and researchers discover when they test the LightMathematics governed
reliance service.

Useful contributions may include:
- counterexamples and failure cases;
- reproducible reliance defects;
- dependency discoveries;
- contradictory or superseding evidence;
- provenance/currentness/authority problems;
- benchmark candidates;
- comparator-equivalent results;
- reproduction and non-reproduction reports;
- proposed corrections supported by evidence.

Favorable, null, adverse and failed results are all eligible for preservation.

## Intake boundary

Raw external submissions must pass through a controlled service-side intake
pipeline before publication here:

**Agent submission → private intake/quarantine → validation and sanitization →
provenance/rights checks → duplicate/conflict/reproduction checks → governed
review → public contribution record, when appropriate.**

Never:

**Agent → direct write to this repository → canonical admission**

and never:

**Agent → canonical LightMathematics corpus**

The private intake/quarantine system may be implemented separately from this
public repository. This public repository must not be used as an unrestricted
upload destination.

## Public contribution states

Published records may use statuses including:

- REPRODUCED
- NOT_REPRODUCED
- DUPLICATE
- CONFLICT
- RETAINED_OBSERVATION
- BENCHMARK_CANDIDATE
- EVIDENCE_CANDIDATE
- RESEARCH_CANDIDATE
- LM_FAILURE
- COMPARATOR_EQUIVALENT
- REJECTED_WITH_RECORD
- REVIEW_REQUIRED

A status describes the contribution's review state. It does not confer canonical
authority.

## Canonicality invariant

**Publication is not admission.**

No contribution becomes canonical merely because it:
- was submitted by an agent;
- was paid for;
- was reproduced;
- appears in this repository;
- receives attention, stars or citations;
- supports a LightMathematics hypothesis.

Any canonical admission requires the separately governed LightMathematics
admission process.

## Security and privacy

Do not publish:
- wallet private keys, seed phrases or signing secrets;
- unrestricted GitHub/service credentials;
- browser-exposed privileged credentials;
- personal or confidential information without an appropriate lawful basis and
  publication authorization;
- malicious executable payloads;
- private canonical-repository material merely because an agent submitted it.

Contributions should be sanitized and bounded before publication.

## Scientific role

Over time this repository may form an open challenge corpus for governed semantic
reliance: reproducible examples where information was stale, unsupported,
mis-authorized, dependency-incomplete, provenance-deficient, unresolved, or
otherwise inappropriate for a declared operation.

The repository must preserve meaningful failures and comparator equivalence, not
only favorable examples.
